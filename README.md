# Modelos do RadFlow Viewer

Pesos de IA opcionais, baixados pelo RadFlow Viewer quando o médico pede. Cada conjunto fica numa Release.

## total-1.5mm-v1

Cinco redes do **TotalSegmentator**, tarefa `total` em 1,5 mm (Dataset291 a Dataset295), convertidas de PyTorch para ONNX sem mudança nos pesos.

- Projeto original: https://github.com/wasserth/TotalSegmentator
- Licença: Apache-2.0 (arquivo `LICENSE` e `NOTICE` deste repositório)
- Citação: Wasserthal J, Breit HC, Meyer MT, et al. TotalSegmentator: Robust Segmentation of 104 Anatomic Structures in CT Images. Radiol Artif Intell. 2023;5(5):e230024.

O TotalSegmentator não é dispositivo médico e não se destina a uso clínico. Estes arquivos são para teste.
